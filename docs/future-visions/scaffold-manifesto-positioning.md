## 1. La Thèse Fondatrice : Pourquoi Scaffold™ est Indispensable

Tous les outils de création actuels souffrent d'une asymétrie fatale :
* **Figma & Framer ne traitent QUE la surface visuelle** : Ils ignorent totalement le backend, les modèles de données relationnels, les règles métier et la plomberie d'ingénierie.
* **Les agents de code (Claude Code, Cursor) ne traitent QUE le code brut** : Ils codent à l'aveugle sans maquette, inventent des interfaces incohérentes et dérivent dès que le projet dépasse 3 fichiers.
* **Les générateurs complets (Bolt, Lovable, v0) essaient de TOUT faire** : Ils promettent une application complète en un clic mais livrent des spaghettis de code ingérables, enfermés dans un hébergement propriétaire fragile (*vendor lock-in*).

### 💎 Le Créneau Souverain de Scaffold™ : La Double Position Logicielle
Scaffold™ ne rivalise pas avec les agents de programmation : **il les rend infaillibles**.  
Scaffold est le seul outil au monde qui livre simultanément :
1. **Une Position Logicielle Frontend** : Maquettes réelles interactives, ergonomie, coquille applicative (Shell), 12 tokens de design, captures d'écrans HD et parcours utilisateurs complets.
2. **Une Position Logicielle Backend** : Modélisation déterministe des entités (`data-shape.md`), règles de persistance, stacks certifiées (Supabase, Neon, Bun, Cloudflare D1) et contrats d'API stricts.

## 3. Positionnement dans l'Écosystème & Modèle Économique

### 🤝 Complémentarité Totale avec les Agents de Programmation
Scaffold™ ne cherche pas à exécuter le code en production ni à héberger les bases de données.  
Il se positionne en amont : **The Pre-Code Intelligence Layer**.
* Le client conçoit gratuitement sur Scaffold.
* Le client valide la maquette et les règles du backend.
* Le client paye pour emporter son package **`blueprint/`** (9 € / 6 000 FCFA en V1).
* Le client confie ce package à son agent préféré (**Claude Code**, **Cursor**, **Codex**) qui exécute les jalons à la perfection dès la première passe.

### 📈 Trajectoire de Valeur & Montée en Puissance
* **Version 1 (Actuelle)** : Cadrage déterministe, 43 presets de design, Live Canvas WYSIWYB, architecture backend/frontend, export `blueprint/` avec prompts 4 piliers.
* **Versions Futures (V2 / V3)** : Agent Designer traçant les wireframes en direct (squelettes vectoriels) avant habillage haute-fidélité, couverture étendue aux Landing Pages complètes et flux de conversion, et réévaluation progressive de la tarification à mesure que la valeur livrée devient insurpassable.
